# 知时 Kairos · 才干罗盘

一个单文件网页测评：把 34 项才干两两对比，强制取舍到前五，再推出你的「用力方式」。

不是 Gallup 官方产品，不联网、不上传、不注册，所有选择只留在你自己的设备上。

## 在线体验

https://timelyrain017.github.io/kairos-talent-compass/

## 它怎么工作

1. **34 → 17 → 9 → 5**：四轮两两对比，每轮必须选一个，不许并列。
2. **可捞回**：每轮结束前能救回一项，避免手滑。
3. **五选定序**：最后从五个里排出前五的顺序。
4. **出结果**：四大域（洞察 / 落地 / 连接 / 推动）雷达图 + 16 型原型 + 前五才干解读 + 耗电清单。

大约 3 分钟，30 多次点击。

## 特点

- 单文件 HTML，零依赖、零后端、零构建
- 结果编码进 URL（40 位），可直接分享给别人看
- 结果卡由 canvas 生成 1080×1920 图片，可直接存图发社交平台
- localStorage 续做，中途退出不丢进度
